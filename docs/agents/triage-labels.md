# Triage Labels

各技能用五个规范化的分诊角色说话。本文件把角色映射到本仓库 issue tracker 里实际使用的标签字符串。

本仓库保留默认值：每个角色的标签字符串与其角色名相同。

| Label in mattpocock/skills | Label in our tracker | Meaning |
| -------------------------- | -------------------- | ------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这张票 |
| `needs-info`               | `needs-info`         | 等待报告者补充信息 |
| `ready-for-agent`          | `ready-for-agent`    | 已完全明确，可交给 AFK agent |
| `ready-for-human`          | `ready-for-human`    | 需要人来实现 |
| `wontfix`                  | `wontfix`            | 不会处理 |

当某个技能提到一个角色时（例如「打上 AFK-ready 分诊标签」），使用上表对应的标签字符串。

颜色定义见 `label-colors.yaml`。要改成本仓库已有的词汇时，改右边这一列。
